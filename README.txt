DupePlugin 1.0.0 - Paper 1.21.11 (Java 21)

USAGE
  Hold any item in your main hand -> type /dupe -> item is doubled.
  Only the player named VyronYT can use it (change in plugins/DupePlugin/config.yml).

BUILD
  Local:   mvn package        -> target/DupePlugin-1.0.0.jar
  Cloud:   push this folder to a GitHub repo -> Actions tab -> "Build plugin"
           -> download the DupePlugin artifact (contains the .jar).

INSTALL
  Put the .jar in your server's /plugins folder and restart.
